# Final report

Compact, in this form:

```text
Implemented
- ...

Changed areas
- path/file: purpose

Validation
- Build: successful / failed / not run
- Tests: successful / failed / not run
- Other checks: ...

Important decisions
- ...

Open points or risks
- none
```

No long retelling of the work steps. Name changes to infrastructure, auth, permissions, CI/CD, schemas or production-near config explicitly. Never claim tests are green if they were not run.

**Why:** Reports are read again on every later step; a retelling of work steps costs context and buries the open points and risks the reader must act on.
